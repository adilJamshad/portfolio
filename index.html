Engineering note · RFC RAG Pipeline

What I learned when I changed models

I started with a local model, tried Gemini, and eventually moved answer generation to Groq. The hard part was figuring out which changes meant I had to rebuild the search index.

Search compares a question’s embedding with the embeddings already stored for the RFC sections. I learned that both need to come from the same embedding model. Changing that model meant re-embedding the corpus. Once I separated retrieval from answer generation, I could keep embeddings local and change the chat model without rebuilding the index.
